# Logbook Skripsi, 10 November 2026

## Kegiatan hari ini
Hari ini saya mengerjakan program yang membuat komputer dan mikrokontroler bisa "berbicara" dengan chip keamanan DS28E38. Chip ini bisa membuat **tanda tangan digital**, yaitu bukti bahwa sebuah pesan atau dokumen benar-benar disahkan oleh chip tersebut. Kunci rahasia untuk membuat tanda tangan itu tersimpan di dalam chip dan tidak pernah keluar.

## Pekerjaan yang diselesaikan

**1. Program penghubung komputer dengan chip (Python)**
Saya membuat program yang mengirim perintah dari komputer ke chip DS28E38 dan DS2476 lewat alat penghubung USB (DS9481P-300). Program ini bisa membaca informasi chip dan meminta chip membuat tanda tangan. Operasi yang bersifat permanen dan tidak bisa dibatalkan sengaja dikunci agar tidak terjadi kesalahan yang merusak chip. Saya juga membuat program uji agar bagian-bagiannya bisa dicek satu per satu.

**2. Program tanda tangan dan pengecekan**
Saya membuat program dengan tiga fungsi sederhana:
- melihat identitas dan kunci publik chip,
- menandatangani pesan atau file,
- memeriksa apakah tanda tangan itu asli, dan pemeriksaan ini tidak membutuhkan chip.

Dalam pengujian, tanda tangan yang asli dinyatakan valid. Pesan yang diubah atau tanda tangan yang dirusak ditolak.

**3. Versi bahasa C**
Program tanda tangan tadi saya tulis ulang dalam bahasa C supaya lebih ringan dan lebih dekat ke program mikrokontroler. Hasilnya cocok dengan versi Python: tanda tangan dari satu versi bisa diperiksa oleh versi lainnya.

**4. Program untuk mikrokontroler STM32**
Saya mulai membuat program sederhana di papan STM32. Papan ini menerima perintah teks dari komputer lewat USB (misalnya meminta ID chip atau meminta tanda tangan), lalu meneruskannya ke chip DS28E38. Program ini masih dalam tahap awal.

**5. Alat bantu**
- Saya menyesuaikan pengaturan proyek agar pemasangan program ke papan lewat ST-Link.
- Saya membuat program monitor untuk mengetik perintah dan melihat balasan dari papan. Program ini bisa menyambung ulang sendiri setelah papan dicolok ulang.

## Kendala
- Program STM32 saat ini masih dalam keadaan nonaktif (ditandai sebagai komentar), jadi belum bisa dijalankan di papan.
- Dokumentasi masih perlu dirapikan. Ada bagian yang menyebut program sudah diuji di perangkat asli, ada juga yang menyebut belum.

## Rencana berikutnya
1. Mengaktifkan dan menguji program STM32 sampai bisa meminta tanda tangan dari chip.
2. Mencocokkan hasil tanda tangan dari papan STM32 dengan program pemeriksa di komputer.
3. Merapikan dokumentasi dan menyimpan pekerjaan ke repositori.
