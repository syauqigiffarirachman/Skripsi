# Logbook 17 November 2026: varian Deep Sleep (Stop), langkah 1-4

Rencana lengkap: `docs/referensi/rencana_deep_sleep.md`.

## Latar

IDLE host tahap D ~11,6 mA (terbaca, shunt nominal) karena mode tidurnya Sleep (WFI) @48 MHz: hanya clock
inti berhenti, PLL/bus/periferal tetap jalan. Angka 1-20 uA berlaku untuk Stop mode tingkat chip.

## Langkah 1: keputusan

- Stop mode DITAMBAHKAN sebagai varian; data tahap D tetap dipakai.
- Titik ukur tetap input 5 V USB-C (lantai papan ~40 uA karena LDO).

## Langkah 2: papan host (sebagian)

- Catu: modul USB-C 5 V -> pin 5V Blue Pill. LDO marking LB2K = XC6219B332MR (Iq 25 uA typ, 50 maks).
- Resistor LED power papan dilepas. LED PC13 Blue Pill tetap terpasang.
- Kristal LSE: Epson MC-306 32,768 kHz (CL standar 12,5 pF, ESR maks 50 kOhm, +-20 ppm). PC14/PC15 bebas.
- DS28E38 hanya IO+GND (parasit); jumper VCC/CEXT DS9121AQ+ belum diverifikasi kontinuitasnya.
- Belum: ukur ulang IDLE Sleep setelah LED dilepas, foto papan.

## Langkah 4: S0a uji LSE (env `host_s0a_lse`, `host_s0a_lse_dingin`, skrip `tools/s0a_lse.py`)

Firmware: BDRST tiap boot, LSEON (batas 6 s), RTC PRL 4095 -> SECF 8 Hz membalik PB1 (kotak 4 Hz ke
logger PA0), RTCCLK/64 di PC13, status `S0A,...` tiap 1 s lewat USART1. Logger perintah 7 (rekam saja).
Hasil: `data/dev/s0a/ringkasan.csv` (25 uji).

| Kelompok | n | lse_start_ms | ppm vs logger | sd periode | tepi hilang |
|---|---|---|---|---|---|
| Pertama setelah flash (start dingin alami) | 1 | 3437 | -47,3 | 0,035 us | 0 |
| Reset ST-Link (kristal masih bergetar) | 10 | 295-305 | -47,2..-47,3 | 0,03-0,08 us | 0 |
| Start dingin firmware (LSE mati 15 s) | 10 | 3503-4073 (rata 3788) | -47,3..-47,4 | - | 0 |
| Setelah kabel dipasang ulang / "power-cycle" | 2 | 300-332 | -47,3 | ~0,04 us | 0 |
| GUGUR (kabel host-logger lepas) | 2 | - | - | - | - |

**Langkah 4 LULUS:** LSE start di 23/23 uji sah, frekuensi stabil (selisih antar uji <= 0,2 ppm).

Catatan:
1. Start dingin LSE ~3,5-4,1 s. Firmware Stop berikutnya: batas tunggu LSE >= 10 s, dan LSE dinyalakan
   sekali saat boot (bukan per jendela).
2. -47 ppm adalah selisih TETAP kristal host vs kristal logger; tak bisa dipisahkan tanpa acuan ketiga.
   Dampak ~2,8 ms per 60 s; T_obs tetap dari logger.
3. Reset biasa BUKAN uji start dingin (Q kristal tinggi, getaran meluruh orde 1 s) -> varian
   `host_s0a_lse_dingin` menunggu 15 s dengan LSE mati.
4. **Daya balik:** USB-C host dicabut, LED PC13 tetap menyala redup -> host tetap berdaya lewat kabel sinyal
   (logger PA9 TX diam tinggi -> host PA10; attacker PA9 -> 1 kOhm -> host PA3), lewat dioda proteksi.
   Power-cycle lewat USB-C tidak mematikan host. Untuk Stop mode ini jalur bocor arus yang harus ditangani
   di langkah 10 (dan mungkin lebih awal, karena mengganggu lantai di langkah 5).
5. Dua uji gugur karena kabel host-logger (GND/PB1/USART1) terlepas saat ST-Link dicabut; ditemukan lewat
   SWD (host jalan, PB1 membalik, RXNE host kosong). Saat mencabut ST-Link, tahan kabel antarpapan.

Host saat ini berisi `host_s0a_lse_dingin` (bukan K1/K2). Flash ulang K1/K2 sebelum mengambil data tahap D lagi.

## Resistor seri (sore)

R seri 10 kOhm dipasang di logger PA9 -> host PA10 dan attacker PA9 -> host PA3 (ganti 1 kOhm). Host tanpa
USB-C/ST-Link tetap 1,92 V di 3V3 dan 5V (rail terkunci di ambang POR/PDR ~1,9 V: di bawahnya MCU hampir
tak menarik arus), tetapi arus injeksi kini dibatasi (~<= 0,1 mA per jalur, belum diukur). GND host-logger
dilepas -> 3V3 0,56 V, 5V 0,16 V. UART + PB1 normal dengan R terpasang (uji S0a LULUS, -47,5 ppm).
Dugaan: pergeseran +0,78 mA 15 Nov = MCU tersangkut setengah-reset akibat daya balik.
Prosedur POR bersih: cabut ST-Link -> cabut USB-C -> lepas GND host-logger -> tunggu 10 s -> sambung GND
DULU -> colok USB-C.

## Langkah 5: S0 Stop minimal (env `host_s0_stop`, `tools/s0_stop.py`, data `data/dev/s0/`)

Jendela aman 5 s (PB1 = 1), BDRST, DBGMCU_CR = 0, semua pin analog kecuali PA13/PA14, jam periferal mati,
build tanpa USB CDC, Stop LPDS selamanya.

| Kondisi | Arus input 5 V (rshunt 0,1, offset -2 LSB) |
|---|---|
| CPU jalan @48 MHz (S0a) | ~13,0 mA |
| Stop, ST-Link terpasang (setelah flash) | 2,567 mA |
| Stop, ST-Link dicabut, POR bersih | **1,985 mA** (sd 1,0 LSB, n 14922) |

- ST-Link + domain debug menyumbang ~0,58 mA -> pengukuran Stop WAJIB tanpa ST-Link dan setelah POR bersih.
- Sisa ~2 mA didominasi LED PWR merah Blue Pill (selalu menyala; MCU Stop + LDO hanya puluhan uA).
  KEPUTUSAN USER: LED dipertahankan, lantai ~2 mA diterima. Konsekuensi: lantai = beban tetap papan yang juga
  ada di tahap D -> selisih/energi dinamis tetap sebanding; nilai mutlak dilaporkan sebagai tingkat papan.
- Instrumen uA (langkah 3) tidak diperlukan: 2 mA = ~80 LSB INA226.
- Host kini berisi `host_s0_stop`.
